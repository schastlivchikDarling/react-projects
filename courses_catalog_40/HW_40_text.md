# Домашнее задание № 40. 

##  React — электронная библиотека с фильтрацией по жанрам

Тема: Props, `children`, `map()`, `filter()`, `key`, условный рендеринг.

 

Среда разработки: WebStorm, React, Vite, JavaScript, JSX, CSS.

Ограничения: запрещено использовать `useState`, `useEffect`, обработчики событий (`onClick`, `onChange`), Redux и другие механизмы управления состоянием.

## 1. Цель домашнего задания

Разработать небольшое React-приложение My Library — электронный каталог книг с разделением по жанрам.

Следует закрепить следующие темы:

1. Создание функциональных компонентов React.
2. Передача данных через `props`.
3. Использование `children`.
4. Отображение массивов с помощью `map()`.
5. Фильтрация массивов с помощью `filter()`.
6. Использование `key`.
7. Условный рендеринг с помощью `&&`, тернарного оператора и `if`.
8. Разделение приложения на независимые компоненты.

### Важное уточнение о фильтрации

Поскольку вы ещё не изучали состояние React, интерактивное переключение жанров через выпадающий список пока не реализуем.

Вместо этого сделаем фильтрацию через параметры компонентов.

На одной странице будут отображаться:

- Общая статистика библиотеки.
- Полный каталог книг.
- Отдельный раздел «Художественная литература».
- Отдельный раздел «Учебная литература».
- Отдельный раздел «Детская литература».
- Отдельный раздел «Публицистика».
- Отдельный раздел «Научно-популярная литература».

Для каждого раздела будет использоваться один и тот же компонент `BookList`, которому передаётся название жанра.

 

## 2. Постановка задачи

Небольшая библиотека хочет создать веб-приложение для просмотра своего книжного фонда.

Для каждой книги необходимо показывать:

- название;
- автора;
- год издания;
- жанр;
- количество доступных экземпляров;
- статус доступности;
- дополнительную отметку для книг, выпущенных до 2000 года.

Книги должны быть распределены по жанрам.

Приложение должно использовать единый исходный массив книг. Создавать отдельные массивы вручную для каждого жанра запрещено.

## 3. Категории литературы

Используем пять категорий:

1. Художественная литература.
2. Учебная литература.
3. Детская литература.
4. Публицистика.
5. Научно-популярная литература.

Каждая книга относится к одной категории.

## 5. Требования к приложению

### 5.1. Общая статистика

В верхней части страницы показать:

```
Всего книг в каталоге: 8
Доступны для выдачи: 6
```

Здесь считается количество наименований, а не сумма физических экземпляров.

Для подсчёта доступных наименований необходимо использовать `filter()`.

### 5.2. Полный каталог

Отобразить все восемь книг.

Для каждой книги создать отдельный компонент `BookCard` с помощью `map()`.

### 5.3. Разделы по жанрам

Ниже полного каталога разместить отдельные разделы.

Например:

```
Художественная литература

1984
Animal Farm

Учебная литература

Clean Code
The Pragmatic Programmer

Детская литература

The Hobbit
The Little Prince
```

Для каждого раздела необходимо использовать компонент `BookList` с соответствующим значением `genre`.

Фильтрация должна происходить внутри `BookList`.

### 5.4. Статус доступности

Если `copies > 0`, показывать:

```
Доступна
```

Иначе:

```
Нет в наличии
```

Для выбора текста и CSS-класса использовать тернарный оператор.

### 5.5. Классическое издание

Если книга выпущена до 2000 года, показывать:

```
Классическое издание
```

Для этого использовать оператор `&&`.

### 5.6. Пустой результат

Если по указанному жанру книг нет, показывать:

```
В выбранной категории книги отсутствуют.
```

### 5.7. Универсальная карточка

Создать компонент `Card`, использующий `children`.

Он должен отвечать только за внешний контейнер и оформление карточки.

## Устранение повторяющегося кода

В текущем `App.jsx` мы несколько раз пишем:

```
<h2>Название жанра</h2>

<BookList
    books={books}
    genre="Название жанра"
/>
```

Нужно ***улучшить код***, создав массив жанров:

```
const genres = [
    "Художественная литература",
    "Учебная литература",
    "Детская литература",
    "Публицистика",
    "Научно-популярная литература"
];
```

И заменить повторяющиеся элементы одним выражением `map()`.
